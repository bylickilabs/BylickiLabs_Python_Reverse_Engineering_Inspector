### [1.0.0] - 2026-08-08

#### Added

* First public release of BPREI
* Static analysis of complete Python projects
* Support for `.py` and `.pyw`
* Project Explorer and source code view
* Analysis of classes, functions, methods, and asynchronous symbols
* Parameter and decorator analysis
* Import and dependency analysis
* Classification into standard library, project internal, and third party dependencies
* Direct function call analysis
* AST based complexity analysis
* NumPy based project metrics
* SciPy Z Score anomaly detection
* Static risk pattern analysis
* Python bytecode inspection using `dis`
* Local SQLite analysis history
* Export to JSON, CSV, HTML, and Markdown
* German and English user interface
* Runtime language switching
* Background analysis using `QThread`
* Cancellation of running analyses
* Windows start and build scripts
* `pyproject.toml` for centralized Python project configuration
* `BPREI.spec` for the structured PyInstaller build
